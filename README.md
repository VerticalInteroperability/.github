# .github

Organization-wide files for **Vertical Interoperability** (VECTOR) on GitHub:

- `profile/README.md`: the organization's public profile page.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `PULL_REQUEST_TEMPLATE.md`: defaults that apply to every
  repository in the organization that doesn't have its own.

Website: https://verticalinteroperability.org
